In this Jupyter Notebook File I have compared the performance of 7 different metaheuristics techniques.

The value of decision variables ranges from 0 to 30 for the function.

TECHNIQUES COMPARED:
1. Binary Coded Genetic Algorithm (BCGA)
2. Real Coded Genetic Algorithm (RCGA)
3. Particle Swarm Optimization (PSO)
4. Teaching - Learning Based Optimization (TLBO)
5. Differential Evolution (DE)
6. Artificial Bee Colony (ABC)
7. Ant Colony Optimization (ACO)

TLBO comes out as the best performing algorithm and BCGA as the worst performing algorithm.
